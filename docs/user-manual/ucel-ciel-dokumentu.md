# Účel a cieľ dokumentu

Tento dokument slúži ako podrobný návod pre používateľov informačného a monitorovacieho systému Plánu obnovy (ISPO). Jeho cieľom je poskytnúť jasné a zrozumiteľné informácie o fungovaní systému ISPO, jeho verejnej a neverejnej časti, a o spôsoboch, akými môžu vykonávatelia a sprostredkovatelia vykonávať administratívne úkony potrebné pre implementáciu Plánu obnovy a odolnosti.

Hlavným cieľom tohto manuálu je uľahčiť využívanie ISPO pri práci s výzvami, žiadosťami a monitorovaním procesov Plánu obnovy na národnej úrovni. Dokument je určený pre vykonávateľov a sprostredkovateľov, ktorí sa podieľajú na implementácii tohto plánu.
